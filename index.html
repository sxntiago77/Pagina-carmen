01

Variables

Guardar datos en memoria

Una variable es un contenedor etiquetado donde guardas información para reutilizarla o modificarla en tu programa.

app.js
12345 
// 'let' para valores cambiantes
let puntos = 0;
puntos = puntos + 10;

// 'const' para valores fijos
const usuario = "Carlos";
02

Funciones

Bloques reutilizables

Una función reúne un grupo de instrucciones para ejecutarlas secuencialmente cada vez que la invoques.

app.js
12345 
function saludar(nombre) {
  return "¡Hola, " + nombre + "!";
}

let msg = saludar("Ana");
console.log(msg);
03

Condicionales

Toma de decisiones

El bloque if / else evalúa una condición lógica para decidir qué camino debe tomar el código.

app.js
123456 
let edad = 18;

if (edad >= 18) {
  console.log("Acceso permitido");
} else {
  console.log("Acceso denegado");
}
04

Arrays / Arreglos

Listas estructuradas

Un Array te permite almacenar colecciones de datos en una sola variable indexada mediante corchetes [].

app.js
123456 
let frutas = ["Manzana", "Banano"];

// Primer elemento (índice 0)
console.log(frutas[0]);

// Añadir elemento al final
frutas.push("Uva");
05

Bucles / Ciclos

Repetición automatizada

El bucle for ejecuta un bloque de instrucciones de forma repetitiva mientras se cumpla una condición.

app.js
12345678 
// Bucle simple del 1 al 3
for (let i = 1; i <= 3; i++) {
  console.log("Número: " + i);
}

// Recorrer un arreglo
let amigos = ["Juan", "María", "Pedro"];
for (let i = 0; i < amigos.length; i++) {
  console.log("Hola, " + amigos[i]);
}
